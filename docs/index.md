## Getting Started

### Prerequisites

- Python 3.12+ for BMAD scripts
- Cursor with BMAD agent skills installed

### Setup

```powershell
# Verify Python
& "$env:LOCALAPPDATA\Programs\Python\Python312\python.exe" --version

# Verify BMAD config
Get-Content _bmad\bmm\config.yaml
```

### Recommended Next Steps

1. Review [architecture.md](./architecture.md) for target system design
2. Run **`bmad-create-architecture`** to lock technology choices
3. Complete **`bmad-generate-project-context`** (reply `C` in that workflow)
4. Begin implementation, then re-run **`bmad-document-project`** with Deep Scan
