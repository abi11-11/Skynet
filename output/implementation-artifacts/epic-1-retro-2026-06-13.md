## 🌟 Successes & Strengths
- **Rapid Monorepo Setup:** Scaffolding the workspace, Vite, and Expo applications went incredibly smoothly.
- **Shared Type Validation:** Enforcing strict PostGIS/GeoJSON types in `@skynet/types` early in Story 1.3 saved future technical debt.
- **Offline Fallback UI:** The proactive caching strategy developed in Story 1.4 works seamlessly on both web and mobile platforms.

## 🚧 Challenges & Growth Areas
- **Brittle Testing Ecosystems:** Getting Jest to work with Expo and Babel inside an NPM workspace consumed massive amounts of time. Moving to `ts-jest` eventually solved it, but it was a painful bottleneck.
- **Local Database Environment:** Due to missing Docker/WSL configuration, we could not validate Row Level Security (RLS) policies locally. This meant we deployed migration scripts essentially blind to their actual execution safety.
